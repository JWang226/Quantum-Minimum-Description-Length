    How to check that the statements match¶

    Each paper label opens the corresponding source line. Each Lean name opens its compiled statement in the explorer; the adjacent source link locates the proof. Definition records a mathematical object, supporting bound proved records a sufficient estimate, and consequence of Article records a specialization of an existing theorem. Read the coverage notes before treating an entry as a formalization of a more general manuscript claim.

    The correspondence is a reviewable interpretation of the manuscripts. To assess a row, compare the source statement with the Lean type and its source declaration, then unfold the definitions linked from the explorer. For the two main theorems, check:

    Feature What the formal statements mean
    Spectrum and limit Dimension and spectrum stay fixed as \(n\to\infty\). The \(r\) positive eigenvalues are distinct, decreasing and normalized; the remaining eigenvalues are zero. Lean uses zero-based indices.
    Source and error Theorem 1 uses the actual matrix \((U\operatorname{diag}(x)U^\dagger)^{\otimes n}\); Theorem 2 uses normalized irreducible-representation orbit states. Both use global \(\tfrac12\|\cdot\|_1\). Theorem 1's reliability is a supremum over the unitary eigenbasis or an integral against normalized Haar measure.
    Code and memory Encoders and decoders are CPTP maps independent of the unknown \(U\). Memory is \(\log_2\dim M_n\), including every retained quantum and classical register.
    Theorem 1 quantifiers One achieving code sequence has error \(O(\log n/\sqrt n)\) and the exact additive memory constant. Every vanishing-average-error code sequence obeys the extended-real liminf converse. Vanishing worst-case error implies the same converse.
    Theorem 2 domain \(d\ge2\); source and target rows are natural, antitone and supported on the first \(r\) positions. Their integral difference is dominant and may have negative entries. \(D\) is the exact row \(\ell^1\) difference. The minimum supported adjacent gap includes the gap to zero when \(r<d\).
    Boundary cases Theorem 1 includes \(d=1\) and every positive rank. Theorem 2 includes rank one and equal source and target rows. Repeated positive eigenvalues are outside these endpoints.
    Intermediate estimates Some proofs use sufficient constants or a target specialization rather than reproduce every displayed manuscript estimate. These differences are recorded in the relevant rows; the final endpoints discharge the representation, dimension, concentration, covariance and transfer premises.

    The achievability statement supplies a particular vanishing-error construction; it does not assert optimal memory for every prescribed error schedule. The Cartan, Choi and Petz identifications concern the canonical pairs needed by Theorem 2. The Letter's memory formulas follow from the Article endpoints; its physical free-entropy volume and offset identities require additional geometric claims, marked above as not formalized.

The Theorem 1 challenges independently restate the physical interface; the Theorem 2 challenge restates Choi contractions while sharing representation, state and projector definitions.
    Nanoda Checks the exported proof dependency closures with a separately implemented kernel.
    Website consistency check Confirms that these tables reproduce the source maps, that manuscript hashes and label locators match, and that the linked Lean declarations occur in the compiled catalog.

    Lean, Comparator and Nanoda check formal objects. Matching an English statement to those objects still requires mathematical review. The source maps are agent-reviewed; independent human correspondence review is not established. The challenge guide describes the shared definitions. See the recorded verification evidence and scope and the reproducer for the completed checks and commands for a fresh run.

    Source maps and maintenance¶

    The tables are generated from the Article correspondence data and Letter correspondence data. TeX labels and fully qualified Lean names identify the statements; line numbers locate them in the current source snapshots. The repository's human-readable correspondence and scope record provides the detailed endpoint interpretation.

    The website deployment checks that the generated tables remain current. To check the documentation locally:

    python3 scripts/generate_correspondence.py --check
mkdocs build --strict

    After an authorized source-map update, regenerate the tables with python3 scripts/generate_correspondence.py. This documentation check is separate from the proof checks documented in the verification guide.
