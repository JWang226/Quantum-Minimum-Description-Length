## Scope

This candidate contains Lean 4 proofs of the current Article's Theorems 1 and 2:
optimal fixed-spectrum quantum memory, with achievability and converse, and
both finite cloning-error bounds for the original Choi-projector channels.
The [correspondence and scope](../correspondence.md) and
[statement audit](../audit.md) record the exact hypotheses, definitions and
paper-to-Lean mappings. Broader Letter geometry and entropy claims are outside

## Reproduce

Install the [verification prerequisites](../verify.md#prerequisites), then:

```sh
git clone --branch v0.1.0-rc1 --single-branch https://github.com/JWang226/Quantum-Minimum-Description-Length.git
cd Quantum-Minimum-Description-Length
bash scripts/verify.sh all
```

Or download `quantum-minimum-description-length-v0.1.0-rc1.tar.gz`, compare its
SHA-256 with the attached release checksum file, and run:

```sh
tar -xzf quantum-minimum-description-length-v0.1.0-rc1.tar.gz
cd free-entropy-formalization
bash scripts/verify.sh all
```

Success ends with `VERIFICATION PASSED: all`. New logs and reports are saved in
the printed `.verify-work/run-*` directory. The [verification guide](../verify.md)
also gives individual Lean, Comparator and Nanoda commands. Bundled reports
describe earlier runs; use the new command's result to assess reproduction.

Lean is pinned to `4.29.0-rc6`; keep the dependency lockfile and checker pins.
The source archive contains the proof and verification inputs, a per-file
checksum manifest, manuscripts and named historical evidence. Historical logs
retain tool-reported local paths. Local website rebuilding uses the full Git
checkout rather than the proof-source archive.
