## Independent source reconstruction

Recorded before reading the Lean endpoints or their definitions. Raw source: `article.tex`, lines 77–99, 645–660 and 923–938.

The source fixes a positive finite dimension d and a density matrix rho of rank r <= d with distinct, strictly decreasing positive eigenvalues x_1 > ... > x_r > 0, remaining eigenvalues zero. Density-matrix normalization entails sum_i x_i = 1. The group is U(d), with rho_g = U(g) rho U(g)^dagger. Neither d nor x varies with n in the limits (line 99).

A code for n is an encoder E_n:B((C^d)^tensor n)->B(M_n) and decoder D_n in the reverse direction, both CPTP, chosen independently of g, where M_n is the sole retained memory including all classical registers. Its cost is log_2 dim M_n, without rounding (lines 77 and 83). Its worst-case reconstruction error is sup_g (1/2)||rho_g^tensor n - D_n(E_n(rho_g^tensor n))||_1 (eq:error, lines 78–80). A stated error allowance delta need only upper-bound this actual error.

The exact leading expression (eq:result, lines 88–90) is
L_{d,r}(n,x) = [r(2d-r-1)/2] log_2 n + sum_{1<=i<j<=r} log_2(x_i-x_j) + (d-r) sum_{i=1}^r log_2 x_i - sum_{k=d-r}^{d-1} log_2(k!).

Achievability quantifiers: for every fixed admissible d, rho (and its r,x), there exists a sequence of codes, hence memories and CPTP pairs indexed by n, for which cost-L tends to zero and actual worst-case error is O(log_2 n / sqrt n). Big-O constants/threshold may depend on fixed d,r,x, not n or g. This is existence of an achieving error schedule, not a claim for every prescribed vanishing schedule (line 99). Theorem achievability explicitly states constant dependence at line 660.

Converse quantifiers: for each fixed admissible d,rho,r,x and every sequence of such codes, if actual worst-case error tends to zero, then liminf_{n->infinity}(cost-L)>=0. The same conclusion follows under the weaker hypothesis that actual error averaged against normalized Haar measure on U(d) tends to zero (Theorem 1 lines 96–97; detailed thm:converse lines 923–938). The liminf can be +infinity. An eventual epsilon lower-bound formulation, for every epsilon>0 eventually cost-L >= -epsilon, would be an equivalent safe encoding avoiding a real-valued liminf default.

No spectral representation interface, cloning estimate, concentration estimate, memory lower-bound assumption, asymptotic target dimension input, or externally supplied error-rate theorem is a premise of Theorem 1. Such objects may be internal constructions/proof steps but cannot be added hypotheses of an unconditional source endpoint.

Potential source convention to check downstream: choice of diagonal reference state is without loss only if unitary conjugacy and Haar/worst-case invariance are justified; arbitrary labels for finite-dimensional memories may encode their dimensions provided CPTP maps have the full source-to-memory and memory-to-source types.

## Carrier, normalization, and convention checks

- **State carrier:** actual complex matrices indexed by `Fin d`; n-fold source is indexed by `Fin n → Fin d`, with entrywise tensor-product formula. `FixedSpectrum` supplies positivity, distinctness, zeros and sum one. A diagonal reference is used; its full U(d) orbit is the known-spectrum family. A formal wrapper for an arbitrary already-given reference rho is outside the reviewed exports.
- **Entire retained memory:** both maps factor through `Matrix (Fin (memory n)) (Fin (memory n)) ℂ`. There is no second decoder input or retained classical register. An arbitrary finite quantum/classical combined memory is represented by this full dimension; the encoder sector sum discards labels.
- **CPTP:** `MatrixChannel` is complex-linear and trace-preserving on all matrices, with positivity for all finite blockwise amplifications. Channel witnesses are actual structures with these proofs. `memory n=0` cannot coexist with a trace-preserving encoder of the trace-one source (fresh positive-memory probe supplied).
- **Errors:** exact factor 1/2 and unnormalized trace of sqrt(X†X). State difference order is harmless by the proved symmetry. Worst error is a genuine bounded, nonempty supremum. Haar is probability Haar on the actual compact unitary group; actual integrability is derived, so the integral is not using a nonintegrable default.
- **Formula/constants:** coefficient uses real subtraction, all sums are zero-based translations of eq:result, factorial interval `[d−r,d)`, and all logarithms use base 2. Cost is log dimension without rounding. The padded target is proved to have that actual dimension asymptotically.
- **Endpoints:** d=1/r=1 is handled by a scalar exact code; d=0 is excluded by density-matrix rank normalization. n=0 totalizations do not affect atTop limits. Unconstrained spectrum entries i≥d do not enter source, cost, or errors.
- **liminf:** real costs are embedded in EReal before Filter.liminf. The proof supplies every eventual epsilon lower bound; +∞ is retained rather than defaulted to a real value.
